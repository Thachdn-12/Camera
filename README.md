# Camera

This project aims to build a complete camera firmware stack, including:

- Camera sensor control
- ISP integration
- Video encoding and streaming
- Audio processing
- AI-based object detection
- Network communication
- Device management
- OTA firmware update

The architecture is designed to be modular, event-driven, and easy to extend for different camera products.

## Features

- Video capture pipeline
- ISP control and tuning
- H.264 / H.265 encoding
- Audio capture and processing
- RTSP streaming
- Wi-Fi / Ethernet connectivity
- AI object detection support
- Configuration management
- OTA update mechanism
- Event-driven application framework
